# 需求文档

## 1. 应用概述

### 1.1 应用名称
霍尔效应模拟实验

### 1.2 应用描述
本应用为三维交互式物理教学仿真网页，模拟载流导体在垂直磁场中的完整动态霍尔效应形成过程。系统通过展示大量连续运动的电子粒子在洛伦兹力作用下的轨迹演变、导体表面电荷积累以及霍尔电场平衡过程，辅助教学演示电磁物理规律。

## 2. 用户与使用场景

### 2.1 目标用户
物理专业教师、学生及电磁学仿真学习者。

### 2.2 核心使用场景
- 教师在课堂中动态演示电子受力偏转、电荷分离积累、霍尔电场建立至稳态平衡的全过程物理机理。
- 学生通过调节实验参数与控制磁极反转，观察不同磁场与电流条件下的微观粒子运动及宏观霍尔电势差变化。

## 3. 页面结构与功能说明

### 3.1 页面架构
```
霍尔效应模拟实验页面
├── 顶部标题与说明区
├── 左侧控制面板
│   ├── 实验开关控制模块
│   │   ├── 霍尔效应模拟开关
│   │   └── 磁场反转开关
│   ├── 参数调节模块
│   │   ├── 电流控制滑块（I）
│   │   └── 磁感应强度控制滑块（B）
│   ├── 物理演化状态指示模块
│   └── 实验数据实时读数模块
└── 右侧三维仿真视口
    ├── 三维坐标系与空间观察

    ├── 动态磁感线展示
    ├── 半透明载流导体薄板（含表面累积电荷层）

```

### 3.2 页面功能说明

#### 3.2.1 顶部标题与说明区
- 页面顶部展示实验标题「霍尔效应模拟实验」。
- 显示原理说明文字：「载流子在垂直磁场中受洛伦兹力偏转并在导体两侧积累，建立横向霍尔电场直至电场力与洛伦兹力动态平衡。」

#### 3.2.2 左侧控制面板
- **霍尔效应模拟开关**：
  - 默认状态为「关闭」：电子粒子沿 +x 方向做纯直线运动，无洛伦兹力偏转与电荷积累；此时允许调节电流大小 I 和磁感应强度 B。
  - 开启状态：触发三阶段动态演化过程，同时锁定电流滑块 I 与磁感应强度滑块 B（变为不可操作禁用状态，但保持当前数值展示）。
- **磁场反转开关**：
  - 默认状态为「关闭」（上 N 极、下 S 极，磁场沿 -z 方向）。
  - 开启状态：平滑交换上下磁铁位置与磁极标注，磁感线反向，电子受力偏转方向与两侧积累电荷极性同步反转，已进行的动画状态平滑过渡而不重置实验。
- **参数调节滑块**：
  - **电流控制滑块（I）**：调节范围 0 至 10，步长 0.1，影响电子粒子发射速率与密度。
  - **磁感应强度控制滑块（B）**：调节范围 0 至 10，步长 0.1，影响洛伦兹力大小与稳态霍尔电压。
- **物理演化状态指示**：
  - 实时高亮显示当前物理过程阶段：「初始直线运动」/「阶段一：洛伦兹力偏转」/「阶段二：电荷分离与积累」/「阶段三：霍尔电场建立与稳态平衡」。
- **实验数据实时读数**：
  - 实时展示当前电流 I、磁感应强度 B、霍尔电场强度 E_H、表面积累电荷量 Q 以及霍尔电压 V_H 数值。

#### 3.2.3 右侧三维仿真视口
- **三维空间与视角交互**：在三维坐标空间中渲染场景，支持通过鼠标拖拽旋转、缩放多角度观察实验装置。
- **永久磁铁模型与磁极反转**：
  - 包含上、下两块永久磁铁模型，默认上方为红色「N极」，下方为蓝色「S极」。
  - 触发磁场反转开关时，上下两块磁铁以平滑动效交换上下空间位置，磁极标识与颜色同步切换。
- **动态磁感线展示**：
  - 绘制连接两磁铁的磁感线箭头，方向由 N 极指向 S 极。
  - 磁感线密度与亮度随参数 B 动态联动，随磁极反转平滑翻转方向。
- **半透明载流导体薄板**：
  - 位于磁铁中间，呈现半透明材质，标注「载流导体」及电流方向。
  - 侧表面具备电荷附着层，可平滑显示正负电荷标记的积累数量与分布极性。
- **连续电子粒子流模拟**：
  - 移除单一静态载流子模型，采用大量白色球形电子粒子（带负电荷 q=-e）。
  - 电子粒子从导体左侧（x 负方向）连续匀速发射并沿 +x 方向进入导体内部流动。
  - 严禁粒子静止、跳变或直接穿透导体边界，碰撞到侧表面的粒子平滑转换为表面积累电荷。

## 4. 业务规则与核心逻辑

### 4.1 霍尔效应动态演化三阶段逻辑
当「霍尔效应模拟开关」开启时，系统按照以下顺序连续平滑推进演化，各阶段不发生突变：
1. **阶段一（洛伦兹力偏转阶段）**：
   - 电子进入磁场区域后受到洛伦兹力 `F = q(v × B)` 作用。
   - 默认磁场下，电子轨迹由初始直线逐渐变为向 +y 方向弯曲的圆弧轨迹（若开启磁场反转则向 -y 方向弯曲）。
2. **阶段二（表面电荷分离与积累阶段）**：
   - 偏转的电子持续碰撞导体侧表面并附着，在 +y 侧表面连续积累负电荷，相对的 -y 侧表面因缺少电子逐渐积累等量正电荷。
   - 表面电荷量从零开始随碰撞次数平滑递增，电荷密度在视觉上从稀疏变为密集。
3. **阶段三（霍尔电场建立与稳态平衡阶段）**：
   - 两侧积累电荷建立横向霍尔电场 `E_H`，对后续运动的电子产生反向静电力 `F_E = q * E_H`。
   - 电子轨迹由圆弧过渡为摆线轨迹；随着 `F_E` 逐渐增大并抵消洛伦兹力，后续进入的电子恢复稳定的直线运动轨迹，系统达到动态平衡稳态。

### 4.2 磁场反转联动逻辑
- 当磁场反转开关切换时：
  - 上下磁铁通过空间平移/旋转完成位置互换，磁感线方向翻转。
  - 电子粒子受力方向反转，向相反侧表面偏转。
  - 两侧积累电荷极性平滑对调（反转后 +y 侧表面积累正电荷，-y 侧表面积累负电荷）。
  - 保持当前的粒子流动与电场建立进程，不重置整体动画。

### 4.3 物理量定量计算规则
- **霍尔电压**：`V_H = k * I * B`（基准比例系数 `k = 0.18`），稳态时达到最大理论值。
- **霍尔电场强度**：`E_H = V_H / d`（`d` 为导体宽度），随表面积累电荷比例平滑递增至稳态。
- **表面积累电荷量**：稳态电荷量 `Q_max = C * V_H`（`C` 为等效电容常数），开启模拟后随时间曲线平滑逼近 `Q_max`。

## 5. 异常与边界情况

| 序号 | 场景 | 表现与处理规则 |
| :--- | :--- | :--- |
| 1 | 模拟开启前将 I 或 B 调为 0 | 开启模拟后电子粒子不发生偏转，保持纯直线运动，E_H 与 V_H 读数保持为 0 |
| 2 | 模拟运行过程中尝试拖动参数滑块 | 滑块处于禁用状态无法拖拽，保持当前固定数值，避免动态破坏平衡过程 |
| 3 | 模拟处于阶段三稳态时关闭模拟开关 | 滑块恢复可操作状态，表面电荷平滑消散，电场 E_H 归零，所有运动中电子平滑恢复直线轨迹 |
| 4 | 在模拟演化进行中频繁切换磁场反转开关 | 磁铁位置与粒子偏转方向执行带插值的平滑过渡动效，不发生粒子穿模、闪烁或突变跳转 |

## 6. 验收标准

1. 控制面板包含霍尔效应模拟开关、磁场反转开关、参数滑块（I、B）、演化阶段指示及实时物理量读数（I、B、E_H、Q、V_H）。
2. 默认关闭模拟时，大量白色电子粒子从导体左侧连续发射并沿 +x 方向做平滑直线流动，滑块可自由调节。
3. 打开模拟开关后，滑块自动锁定为禁用状态，电子粒子平滑经历圆弧偏转、侧壁电荷分离积累、摆线过渡、最终恢复直线稳态运动的全流程。
4. 打开磁场反转开关后，上下磁铁平滑对调位置，磁感线与电子受力方向反向，两侧电荷积累极性同步交换，动画过程保持连续无跳变。
5. 关闭模拟开关后，表面电荷平滑消散，E_H 与 V_H 恢复为零，滑块解锁可重新调节。
6. 读数面板中的霍尔电场强度 E_H、表面电荷量 Q 与霍尔电压 V_H 随着粒子积累与平衡过程实时平滑增长至理论数值。
